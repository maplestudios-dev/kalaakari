# 02 · Brand Strategy

## Story
**Kalaa** (कला) — the art. **Kaari** (कारी) — the maker. **Kalaakaari** (कलाकारी) — craft put into motion. Not a noun. A verb.

## Positioning
A branding-first independent creative studio where strategy, design, content, performance and production converge — Delhi-born, senior-led, craft-first.

## Promise
*We build brands that are remembered, not just seen.*

## Tone of voice
- Confident, not arrogant
- Short sentences. Then one longer one that earns the room.
- Specific over abstract: "the 27-second cut" beats "high-impact creative".
- Hindi accents used as identity, never as decoration.
- We never say "synergize", "leverage", "delight", "elevate", "best-in-class".

## Messaging pillars
1. **Kala** — Craft. The frame, the letterform, the line of code that has rhythm.
2. **Kaari** — Conviction. Maker's intent. Briefs that get sharpened, not just executed.
3. **Culture** — Pulse. Delhi's chaos and contradictions as a creative asset.

## Hindi / English usage principles
- Headlines: English-led, with a Devanagari sub-line for resonance.
- Section labels: Bilingual (e.g., `Pillars · हमारे स्तंभ`).
- Decorative oversized glyphs (क, ला, कलाकारी) act as art direction, not legible copy.
- Devanagari is **never** in lock-up with the wordmark unless intentional (e.g., footer brand block).

## Color usage
| Token | Hex | Use |
|---|---|---|
| `--bg` | #0B0A08 | Default page background |
| `--bg-2` | #100E0B | Secondary surfaces, cards |
| `--ink` | #F4EDE0 | Primary text |
| `--ink-mute` | #9C9486 | Secondary text |
| `--line` | #2A251E | Borders, dividers |
| `--saffron` | #E8631F | Primary accent (1 CTA per section max) |
| `--mustard` | #F5C542 | Devanagari, metric numerals, secondary accent |
| `--clay` | #8C3A1A | Atmospheric gradients only |
| `--parchment` | #E9DCC4 | Italic serif emphasis text |

Avoid SaaS blue, generic startup gradients, flat corporate whites, neon glow, overdone India motifs (no rangoli, no temple ornament).

## Typography (in production)
- **Display**: Anton — hero headlines, project titles, marquee
- **Serif**: Fraunces (italic, 300) — emotional emphasis, quotes
- **Sans / body**: Archivo — UI, labels, body
- **Devanagari**: Tiro Devanagari Hindi — sub-lines, decorative glyphs
